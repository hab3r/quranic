# The Evidence

**Comprehensive, verifiable evidence that the Qur'an is the word of Allah — across seven independent domains. Qur'an-only evidence. No hadith used.**

## What is this?

A multi-page dawah corpus presenting the cumulative case for the divine authorship of the Qur'an. Each evidence domain has its own dedicated page with detailed Arabic analysis, verse references, epistemic labels, and honest objections. Designed for both human readers and AI agents researching for humans.

## The core argument

> A human optimizing for any one domain sacrifices the others. Poetry sacrifices precision. Law sacrifices beauty. Numerology sacrifices naturalness. The Qur'an satisfies all constraints simultaneously — from an unlettered man. The denial requires a bigger miracle than the claim.

## Design principles

1. **Qur'an-only** — No hadith evidence. The evidence chain begins and ends with the Qur'anic text.
2. **Epistemic honesty** — Every claim labeled: verified fact, confirmed description, standing challenge, rejected claim, or interpretation.
3. **Publish failures** — 12 famous numerical claims tested and rejected with real numbers.
4. **State objections first** — The strongest objections are stated at full strength, then answered.
5. **Separate fact from conviction** — The divine authorship conclusion is argued openly, never smuggled into data.
6. **Optimize for both humans and AI** — Clean HTML, structured data, AGENTS.md, llms.txt.

## How to view

Open any `.html` file directly in a browser. No build step, no dependencies, no server required.

Or serve it locally:

```bash
npx serve .
```

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `the-evidence`)
2. Push these files to the `main` branch
3. Go to **Settings > Pages** and set source to **Deploy from a branch** / `main` / `/ (root)`
4. Update `USERNAME` in `sitemap.xml` and `robots.txt` with your GitHub username
5. The site will be live at `https://USERNAME.github.io/the-evidence/`
